# Get started

Release **0.3.0a4** ships a Python library (`RGTools`) and three companion CLIs.
Choose the onboarding path that matches how you plan to work.

## Pick your first success

| Path | Best when you want to… |
| --- | --- |
| [Install](../install.md) | Set up the tagged release and verify console scripts |
| [Python quickstart](python-quickstart.md) | Load genomic regions in code, inspect sequence order, and build one-hot arrays |
| [CLI quickstart](cli-quickstart.md) | Run a zero-input MotifTools smoke test, then export exogenous sequences from synthetic genomic inputs |

Both quickstarts use the same deliberate **synthetic** example assets published
with this site. Download them from the quickstart pages or copy them from a
built checkout under `docs/get-started/assets/`.

After your first run, skim [Concepts](../concepts.md) for shared terminology and
open [Python API](../library.md) or [CLI commands](../reference/cli/index.md) for
exact lookup.
